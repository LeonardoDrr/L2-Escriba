# Gestor de Avance

Para abrir la aplicación y ver todos los cambios localmente, necesitas iniciar un servidor local.

## Cómo iniciar el servidor

Tienes dos opciones muy sencillas:

**Opción 1: Usar el archivo ejecutable (Recomendado)**
Simplemente haz doble clic en el archivo **`start_server.bat`** que se encuentra en esta misma carpeta. Esto abrirá una ventana de comandos e iniciará el servidor automáticamente en el puerto 3000.

**Opción 2: Usar la consola**
1. Abre tu terminal o consola de comandos en esta carpeta.
2. Ejecuta el siguiente comando:
   ```cmd
   npx serve .
   ```

Una vez iniciado el servidor, abre tu navegador web y entra a:
[http://localhost:3000](http://localhost:3000)
